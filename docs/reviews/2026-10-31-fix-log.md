## Remaining known gaps

These need a real device, root, or a running app, so they were not checked here:

- **Panel and Dock on macOS 27**: the `PresenceSwitch` timing when Show in Dock is turned off (R33), the panel resizing as content changes (R6), refocusing an already-open panel and the fade token (R34/R72), Dock Open Panel/Until… anchoring and the session toggle (R92), ⌘W in each window (R94), the Settings frame autosave (R36), and the hidden-item card after the welcome panel (R95).
- **App lifecycle**: a second quit during terminateLater (R7), handing a URL over to a running copy from a second one (R35), and launching from the CLI or a URL without "Start keeping awake at launch" (R31).
- **Makefile and privileged paths**: `make install` quitting and reopening a running copy (R76), and the order of `make uninstall`, including its pmset reset (R1). These were only checked with `make -n` and `sh -n`. The `sudo -n -l` rule probe (R75) wasn't checked against real sudo. The sudoers safety daemon's boot reset (R10) was tested only with stand-in pmset and ioreg. `make uninstall` leaves a possible `lid-engaged.recovered` breadcrumb in Application Support. It does no harm once the app is gone.
- **Closed-lid device tests** T1–T19 and the sudoers-fallback run in docs/CLOSED_LID.md §8 have not been run on this branch. That includes the watchdog's marker and breadcrumb handling (R90), the engage-timeout hand-off (R74), and resuming after another user releases (R89, T17).
- **Watching**: the other-user and root process matching (R19) and the KVO launch/quit for LSUIElement apps (R22) were probed on one Mac only.
